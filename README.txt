SACCADES オフライン対応ファイル一式

【ファイル（すべて同じ階層に置いてください）】
index.html            ゲーム本体
manifest.webmanifest  ホーム画面・Dockに追加するための設定
sw.js                 オフラインで動かすための仕組み
icon-192.png / icon-512.png / icon-maskable-512.png / apple-touch-icon.png / favicon-32.png / icon.svg
                      アイコン画像

【使い方】
1. GitHub Pagesなど、https:// で開けるWebサーバーに、これらのファイルを置きます。
2. 端末で、そのURLを1回オンラインで開くと、以後はオフラインでも動きます。
3. Mac：Safariで「ファイル > Dockに追加」。iPhone/iPad：Safariの共有ボタンから「ホーム画面に追加」。

【更新するとき】
ゲームを調整したら、新しい index.html を同じ場所に上書きアップロードするだけです。
オンラインで開くと、自動で新しい版に切り替わります。
